# Lampa Sleep Timer

Таймер сна для плеера [Lampa](https://github.com/yumata/lampa-source). Добавляет на панель плеера кнопку с луной.

## Возможности

- Выключение через 15 / 30 / 45 / 60 / 90 минут или **до конца серии** (следующая серия не включится).
- Обратный отсчёт прямо на кнопке.
- За минуту до выключения — предупреждение с кнопкой «Ещё 15 минут» (на ТВ продлевает кнопка OK на пульте).
- Когда время выходит, плеер закрывается (Лампа сохраняет позицию как при обычном выходе), экран затемняется.
- Таймер переживает переключение серий. Если выйти из плеера самому, он снимается.

## Установка

Lampa → Настройки → Расширения → Добавить плагин:

```
https://side75.github.io/lampa-sleep-timer/sleep.js
```

## Блокировка устройства

Веб-приложение не может само заблокировать планшет или выключить ТВ. Но после закрытия плеера видео больше не удерживает экран, и устройство засыпает по своей автоблокировке. На iPad: Настройки → Экран и яркость → Автоблокировка → 2 минуты.
