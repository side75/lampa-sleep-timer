# Lampa Sleep Timer

Таймер сна для плеера [Lampa](https://github.com/yumata/lampa-source). Добавляет на панель плеера кнопку с луной.

## Возможности

- Выключение через 15 / 30 / 45 / 60 / 90 минут или **до конца серии** (следующая серия не включится).
- Обратный отсчёт прямо на кнопке.
- За минуту до выключения — предупреждение с кнопкой «Ещё 15 минут» (на ТВ продлевает кнопка OK на пульте).
- Когда время выходит, видео сразу ставится на паузу, плеер закрывается (Лампа сохраняет позицию как при обычном выходе), экран затемняется.
- Пока экран затемнён, сторож раз в секунду останавливает всё, что пытается заиграть: следующую серию, заставку.
- Если видео зависло на подгрузке и 3 минуты не двигается, таймер срабатывает сразу: зависшее видео не стоит на паузе и само не даёт устройству заснуть.
- Таймер переживает переключение серий. Если выйти из плеера самому, он снимается.
- В меню таймера есть «Журнал таймера»: когда его поставили, продлили, когда он сработал и что остановил.

## Установка

Lampa → Настройки → Расширения → Добавить плагин:

```
https://side75.github.io/lampa-sleep-timer/sleep.js
```

## Блокировка устройства

Веб-приложение не может само заблокировать планшет или выключить ТВ. Но после закрытия плеера видео больше не удерживает экран, и устройство засыпает по своей автоблокировке. На iPad: Настройки → Экран и яркость → Автоблокировка → 2 минуты.

### Настоящая блокировка iPad / iPhone

Плагин может запустить команду из приложения «Команды», которая блокирует экран сразу (iPadOS / iOS 16.4 и новее):

1. В приложении «Команды» создайте команду из одного действия «Заблокировать экран» и назовите её `LampaLock`.
2. В меню таймера нажмите «Блокировать планшет», чтобы стало «да».
3. Нажмите «Проверить блокировку» и не трогайте устройство: через 10 секунд оно должно заблокироваться.

Если при проверке появляется вопрос «Открыть в приложении „Команды“?» или ничего не происходит, значит ваша оболочка Лампы не даёт открыть команду без подтверждения. Тогда остаётся автоблокировка.
